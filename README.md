# 🎓 PeerSync - Plateforme de Tutorat ENAA

PeerSync is a web-based tutoring platform that connects students and tutors to help manage and resolve academic help requests efficiently. Students can submit requests, tutors can assign themselves, resolve issues, and users can leave reviews.

## 🚀 Features

### 👨‍🎓 Students
- Create help requests
- Track request status (Pending / Assigned / Resolved)
- Leave reviews after resolution
- View notifications

### 👨‍🏫 Tutors
- Browse available requests
- Assign requests to themselves
- Add Google Meet link for sessions
- Mark requests as resolved

### 🔔 Notifications System
- Alerts when a request is assigned
- Alerts when request is updated

### ⭐ Reviews System
- Rate tutors (0–5 stars)
- Add comments
- View all reviews per request
